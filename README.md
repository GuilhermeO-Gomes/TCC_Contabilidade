1. Tela historico padrao: Nessa tela o usuario é capaz de criar, editar e inativar historicos padrões da empresa que servem para agilizar os processos e economizar tempo alem de poder limpar os dados em todos os campos.

2. Tela Exercicios Sociais: Nela o usuario é capaz de criar, editar e inativar algum Exercicio. Essa tela serve para contabilizar e listar todos as movimentações(exercicios) da empresa dentro de 1 ano e averiguar se está tudo certo e batendo com as contas e notas fiscais.
